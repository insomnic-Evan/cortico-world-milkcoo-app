移动前端coodock · 使用指南

第一次连接

先让手机找到你的 Coo

  1. 运行 Coo 的主机
  2. 专属安卓安装包
  3. 开始连接

怎么做

  1. 1

    准备主机

    在电脑或服务器运行 Coo，安装并启用“移动前端coodock” World。

  2. 2

    安装专属包

    主机直连时下载“主机版 APK”；若需要手机内核、记忆副本和备用 API 续聊，下载“完整工作台 APK”。两包同包名、同签名，覆盖更新保留连接与数据。

    使用公网中转时，先从公网主页（备用入口）领取密钥，然后在运行 Coo 的电脑上填写中转密钥并生成专属 APK。

  3. 3

    确认连接

    打开左侧菜单“连接与同步”，确认当前连接；也可以手动填写或导入自己的连接。回到对话发送一句测试消息。

记住这些

  • 专属安卓安装包包含这个 Coo 的连接信息，请私下传给自己的手机。
  • 也可通过自己配置的 HTTPS 或可信 VPN 跨网直连。
  • 在“连接与同步”选择异机主线、本机主线或电脑备份续聊。本机与备份续聊需要工作台版；切换不会把原目标的待发消息投递到新主线。

奶coo · 使用指南

完整 Coo 控制台

主机提供的 World、设置和运行界面

  1. 手机入口
  2. 完整界面地址
  3. 主机 Coo

怎么做

  1. 1

    打开入口

    从左侧菜单选择“Coo 控制台”。新版 World 可通过配置“手机上的完整 Coo 控制台地址”提供入口，也可以在手机里点设置手动填写。

  2. 2

    填写完整地址

    使用手机实际能访问的 HTTP(S) 地址，保留域名和反向代理路径。它与手机通道地址独立，不自动改成 7791，也不把手机 localhost 当成服务器。

  3. 3

    使用主机界面

    按 Coo 原有页面完成登录、管理 World 或调整设置。手机不向网页注入通道密钥；界面由主机维护，主机登录状态保存在该 WebView。

  4. 4

    返回或外部打开

    顶部返回关闭控制台；系统返回先后退页面。需要外部网页或浏览器时使用“浏览器打开”。

记住这些

  • 主机只监听自己的回环地址时，手机不能直接访问；使用现有可达的正式界面入口或可信网络。
  • 完整界面不意味着任意桌面 World 的执行能力已迁移到手机。

对话与图片语音

像平常一样聊天

  1. 输入消息
  2. 图片或录音
  3. 发送

怎么做

  1. 1

    发送文字

    在对话页输入文字，点“发送 ↑”。消息会先保存在手机，再由通道尝试送往主机。

  2. 2

    发送图片或语音

    点“图片”选择照片，或点“拍照”；点“录音”开始，再点“停录”发送。图片上限为 8 MiB，录音最长 60 秒。

  3. 3

    查看状态

    “手机已保存 · 待发送”表示还在本机；“服务器已保存”表示主机已接收；“已进入对话上下文”不代表已经生成回复。

记住这些

  • 首次使用相机或麦克风时，请按系统提示授权。
  • 离线内容会保存在手机，联网后再查看发送状态。

随身小人

让小人陪在屏幕上

  1. 主机桌宠
  2. 同步角色
  3. 手机悬浮小人

怎么做

  1. 1

    准备角色

    主机启用桌宠 World；手机首次需要连接主机获取角色资源。

  2. 2

    开启小人

    在侧边栏打开“随身小人”，开启小人并按系统提示允许悬浮窗。可以设置打开应用时自动显示及透明度。

  3. 3

    日常互动

    单击小人显示对话和语音小球，再点击小球打开对应功能；语音识别结果先留在草稿，点击对话小球查看、编辑和发送。也可以拖动小人，或按设置双击看屏幕。系统安全页面可能隐藏悬浮窗。

  4. 4

    添加小人桌面入口

    在“随身小人”点“添加随小人变化的桌面入口”，按桌面提示确认。同步到的新形象可更新该入口，原应用图标仍保留。

记住这些

  • 桌面与手机的位置独立；具体角色的兼容性取决于资源与手机 WebView。

角色与装扮

使用 Coo 自己的角色与换装逻辑

  1. Coo 角色清单
  2. 选择外观
  3. 两端同步

怎么做

  1. 1

    进入装扮

    在“随身小人”点“角色与装扮 · 与 Coo 同步”。选择 Coo 已安装的角色及其装扮，点击“应用外观”。

  2. 2

    导入与移除

    导入 ZIP 后先查看 Coo 给出的检查结果，再勾选角色安装；可移除角色包会显示确认窗口。手机不另建角色格式。

  3. 3

    确认同步

    应用后回读 Coo 的实际外观；手机在后续同步中刷新。位置、透明度保留本机设置。若 Coo 在其他端已更换，请先刷新再修改。

记住这些

  • 需同时更新手机 App 和主机手机通道 World。角色资源仍由当前 Coo 提供。

随身记忆工作台

完整工作台包提供，不影响主机版的日常使用

  1. 共同记忆
  2. 来源与批阅
  3. 主机工作

怎么做

  1. 1

    启动工作台

    主机版不带手机内核。在主机的奶CooApp World 卡片下载“完整工作台 APK”覆盖安装后，才会显示完整工作台菜单。进入时启动控制进程，默认不装任何 World。

  2. 2

    接入共同库

    在“工作台接入”填写已有共同记忆服务地址和密钥。记忆归同一库管理，新的窗口复用已有索引，不重新把旧对话送模型建库。

  3. 3

    查看原文与批阅

    在记忆入口检索和展开来源；原文、时间和来源保留。批阅台需要共同记忆服务提供对应接口；没有配置时会显示不可用。

  4. 4

    管理主机

    电脑设置与 World 通过主机原有控制台接口操作。主机流水显示已有用户、助手和工具记录；配置与状态可另外备份，原文和工作区通过会话快照保存。

记住这些

  • 内置工作台运行时面向 ARM64 安卓。服务器模式不会因打开工作台再创建一个本地模型会话。
  • 主机未提供所需接口时，对应功能显示不可用；手机不会静默替换共同库或主机 World。
  • 从完整包换回主机版会停止使用本端工作台，但原有私有数据目录保留；重新安装完整包可继续使用。
  • 本机 World 插座和对话主线分开：连接电脑时仍可运行本机 World，默认观察只留记录，不启动第二条模型对话。共同记忆改走 SharedGitMem 装配；旧临时蒸馏队列只保留历史，不再写入。

本端侧续聊

带着电脑快照，显式切换到备用 API

  1. 电脑会话快照
  2. 手机续聊
  3. 归还新事实

怎么做

  1. 1

    先准备快照

    进入“本端侧续聊”，连接主机并检查会话快照状态。快照保留主机实际 system、会话记录及工作区字节。

  2. 2

    配置备用 API

    在工作台接入中配置备用模型、API 地址和密钥，然后显式切到本端侧。推理仍由你填写的 API 完成，手机不内置大模型。

  3. 3

    切回主机

    切回服务器时提交手机期间新增的事实；已经执行的工具指令不会作为新指令在主机重放。进行中的回复完成后再切换。

记住这些

  • 这是一条专门的续聊入口；普通奶coo 对话保留原有收发逻辑。
  • 模型 API 仍需网络可达；手机断网并不等于可以离线推理。
  • 此入口需要完整工作台包；主机版连接和正常对话不依赖它。

奶coo · 使用指南

看屏幕

一眼与持续观察都由你开启

  1. 双击小人
  2. 看一眼
  3. 持续观察设置

怎么做

  1. 1

    看一眼

    双击小人后停顿 0.7 秒，才会请求看屏幕；继续戳小人会取消本次请求。系统可能要求屏幕共享授权；没有持续观察时只取一张画面，也可以关闭双击功能。

  2. 2

    持续观察

    在侧边栏打开“看屏幕”，使用页面顶部的开启与停止按钮，调整时间间隔及自适应。

  3. 3

    决定是否主动回应

    默认画面供 Coo 按需查看；选择主动观察时，画面可能触发模型调用并产生费用。

记住这些

  • 默认由 World 按需取帧。先在手机开启设备会话并授权，World 决定何时取一帧、是否唤醒模型；App 不再自行周期上传。要使用旧观察通道，可在“连接与同步”关闭“读屏与相机由 World 按需取帧”，再重开设备会话。
  • 有些系统安全页面会限制截屏或隐藏悬浮窗；模型是否能看懂画面取决于其图像能力。

摄像头观察

由你决定何时开启

  1. 允许相机
  2. 设置画质
  3. 开启观察

怎么做

  1. 1

    打开观察页

    在侧边栏选择“摄像头观察”，点击开启并允许相机。

  2. 2

    调整画面

    选择前后摄、清晰度和基础间隔，按需要开启自适应和主动回应。

  3. 3

    停止

    在页面或系统通知栏停止观察。Coo 可以调整已开启会话的部分参数，但不能自行打开镜头。

记住这些

  • 默认由 World 按需取帧。先在手机开启设备会话并授权，World 决定何时取一帧、是否唤醒模型；App 不再自行周期上传。要使用旧观察通道，可在“连接与同步”关闭“读屏与相机由 World 按需取帧”，再重开设备会话。
  • 这是采样图片的观察通道，不是连续双向视频通话。

事件与提醒

查看 Coo 和 World 的动态

  1. 主机事件
  2. 事件时间线
  3. 通知与提示

怎么做

  1. 1

    查看事件

    在“事件时间线”查看已同步的 Coo 与已接入 World 事件；点条目查看记录。

  2. 2

    调整提醒

    在“通知与提示”按来源设置气泡、通知栏和重要提示，并按需要在系统设置中允许通知。

  3. 3

    理解边界

    事件进入时间线不等于自动向模型发送新消息；不同 World 是否接入、系统省电和权限会影响可见范围与时效。

记住这些

  • 通知栏、横幅与锁屏的最终显示由手机系统决定。

World 与模型

查看扩展，选择主机模型

  1. 浏览 World
  2. 主机安装
  3. 模型与思考

怎么做

  1. 1

    一个 World 管理入口

    “World 扩展”读取当前主线的公开列表和页面清单；工作台入口也回到这里。本机可导入 World 包，明确启用后才运行；异机使用主线的公开界面。

  2. 2

    模型与思考

    打开同一主线的配置界面，不在手机另存一套模型表单。本机模型由本端工作台配置；异机模型使用主机 Coo 控制台。

记住这些

  • 修改的是主机 Coo 的设置，可能影响使用同一主机的其他窗口。

公网 World

在手机里打开星邮和其他网页

  1. 选择 World
  2. 连接站点
  3. 使用站点会话

怎么做

  1. 1

    打开星邮私聊

    点击右上角奶coo 图标，直达星邮“我的 bot”私聊；再点一次回到之前的页面。首次使用时按网页提示登录。也可从侧边栏进入“公网 World”打开完整的星邮网页。

  2. 2

    使用其他网页

    在“其他公网 World”填写 HTTPS 网页地址并打开。站点内的内容和功能由该 World 提供。

  3. 3

    返回奶coo

    再次点击右上角图标，或使用手机返回键退出私聊；完整 World 网页可用顶部“入口”返回列表。原有局域网对话仍可从侧边栏打开。

记住这些

  • 星邮网页与奶coo 的局域网通道是两个独立连接；星邮需要对应 World 和账号。
  • 星邮域名首页连接失败时会尝试官方客户端公布的 HTTPS 备用地址；两个地址的网页登录状态分别保存。
  • 站点外的 HTTPS 链接会交给手机浏览器打开。

漂流瓶信箱

在手机上打开 Coo 的海边信箱

  1. 主机启用漂流瓶
  2. 连接奶coo
  3. 打开信箱

怎么做

  1. 1

    准备 World

    在与奶coo 连接的 Coo 或 Cortico 上安装并启用“漂流瓶”；同时更新手机通道 World。

  2. 2

    打开信箱

    在手机左侧菜单选择“漂流瓶”。页面显示的是该 Coo 自己的信箱和草稿。

  3. 3

    寄出与回复

    按信箱页面选择操作。网络中断时先刷新确认结果，避免重复寄出。

记住这些

  • 漂流瓶使用其 World 自己的服务；手机入口随当前 Coo 连接切换。
  • World 默认会定时邀请 Coo 写信或捞信，可能产生模型调用；可在信箱的邀请设置中暂停或调整间隔。

查看与分享日志

先看内容，再自行提交

  1. 选择记录
  2. 预览明文
  3. 自行分享

怎么做

  1. 1

    复现问题

    记下大概时间、手机型号和操作步骤。

  2. 2

    查看日志

    进入“诊断日志”，选对应记录，刷新并阅读预览。闪退后可选择上次运行的文件。

  3. 3

    自行分享或提交

    可通过“分享明文日志”自行选择接收人，或选择“提交当前预览”并确认提交。

  4. 4

    可选的自动反馈

    在“统计与故障反馈设置”中选择是否允许匿名启动统计和自动提交新故障条目；两项默认关闭，可随时关闭。

记住这些

  • 日志包含版本、时间、连接结果、错误代码和媒体大小，不含聊天正文、附件、文件名、地址、连接码和密钥。
  • 开启自动反馈后只上传新发生的固定标签故障条目，不补传历史；离线期间记录可能未送达。日志不能替代系统崩溃报告。
