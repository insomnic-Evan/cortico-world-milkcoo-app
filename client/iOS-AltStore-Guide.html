用 AltStore 安装奶coo

这是尚未在 iPhone 真机验证的测试路线。请按自己的设备和系统提示操作。

先准备好

  • Windows 10 或更新版本电脑、iOS/iPadOS 16 或更新版本的设备及数据线。
  • 苹果账号与网络；账号密码和验证码只由本人在相关软件或苹果页面输入。
  • 运行着 Coo 和“奶CooApp”World 的主机；初次连接可与手机处于同一局域网。
下载未签名 IPA下载官方 AltServer

这份 IPA 尚未签名，不能直接点开安装。AltStore 将尝试使用你的苹果账号为设备签名；本项目尚未实测通过此过程。

1 · 在 Windows 上准备 AltServer

  1. 按 AltStore 官方指南安装 Apple 官网版本的 iTunes、iCloud 和 AltServer。
  2. 启动 AltServer，将 iPhone／iPad 用 USB 接到电脑并解锁；设备询问信任时按提示确认。
  3. 在电脑右下角系统托盘打开 AltServer，选择 Install AltStore 和你的设备；按程序要求由本人登录 Apple 账号，等待安装结果。
查看 AltStore 官方 Windows 指南

2 · 在手机上安装奶coo

  1. 根据系统提示，在“设置 → 通用 → VPN 与设备管理”中信任相应开发者；如系统要求，开启“设置 → 隐私与安全性 → 开发者模式”并按提示重启。
  2. 将下载的 IPA 用你方便的方式保存到 iPhone／iPad 的“文件”中。
  3. 打开 AltStore Classic 的“My Apps”，点左上角“＋”，选取 IPA，等待签名与安装。具体界面以当前版本为准。
  4. 打开奶coo，在电脑 World 的苹果连接页面生成连接码，使用 App 配对。配对码会过期，失效后重新生成。
打开苹果设备连接码

3 · 测试与续期

先测试能否启动和连接，再试文字、图片与语音；遇到问题可在 App 中查看并分享明文诊断日志。免费苹果账号的开发签名通常在 7 天后到期，需要按 AltStore 的流程刷新。AltServer 在线且电脑和手机可连接时，AltStore 可以尝试自动刷新；结果以设备显示为准。卸载 App 可能删除本地数据，请先备份需要保留的内容。
